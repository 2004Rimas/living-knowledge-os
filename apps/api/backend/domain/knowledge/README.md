# Knowledge Domain

Manages semantic knowledge representation, embeddings, and organizational memory.

## Bounded Context

Responsible for:
- Knowledge graph representation
- Semantic relationships
- Vector embeddings and similarity
- Knowledge organization and discovery
- Citation and provenance tracking
- Memory and fact management

## Aggregates

- **KnowledgeNode Aggregate**: Knowledge unit with embeddings and relationships
- **Embedding Aggregate**: Vector representation and metadata
- **Citation Aggregate**: Source attribution and provenance

## Key Entities

### KnowledgeNode
- **Purpose**: Semantic unit of knowledge
- **Attributes**: ID, workspace_id, title, content, type, metadata
- **Relationships**: Has many Embeddings, KnowledgeEdges, Citations
- **Rules**: Immutable once created, tracked for changes
- **Business Rules**: Types: Fact, Concept, Decision, Insight, Process

### KnowledgeEdge
- **Purpose**: Semantic relationships between knowledge nodes
- **Attributes**: ID, source_node_id, target_node_id, relationship_type, weight
- **Relationships**: References two KnowledgeNodes
- **Rules**: Directed, weighted edges
- **Business Rules**: Types: Depends_On, References, Contradicts, Refines, Implements

### KnowledgeCollection
- **Purpose**: Curated sets of related knowledge
- **Attributes**: ID, workspace_id, name, description, owner_id
- **Relationships**: Many-to-many with KnowledgeNodes
- **Rules**: User-created or system-generated

### KnowledgeSource
- **Purpose**: Tracks origin of knowledge
- **Attributes**: ID, type (document, meeting, decision, issue)
- **Relationships**: Links to source entity, KnowledgeNodes
- **Rules**: Enables reverse traceability

### KnowledgeChunk
- **Purpose**: Granular indexable piece of knowledge
- **Attributes**: ID, node_id, content, chunk_index, char_start, char_end
- **Relationships**: Belongs to KnowledgeNode, Has Embeddings
- **Rules**: For chunking large documents

### Embedding
- **Purpose**: Vector representation for semantic search
- **Attributes**: ID, chunk_id, model, vector (pgvector), metadata
- **Relationships**: Belongs to KnowledgeChunk
- **Rules**: Supports multiple embedding models
- **Business Rules**: Vectors stored in pgvector extension

### Citation
- **Purpose**: Attribute knowledge to sources
- **Attributes**: ID, node_id, source_id, confidence_score, page_ref
- **Relationships**: Belongs to KnowledgeNode
- **Rules**: Multiple citations per node

### Memory
- **Purpose**: Organizational learnings and patterns
- **Attributes**: ID, workspace_id, content, pattern, confidence
- **Relationships**: Linked to KnowledgeNodes, Decisions
- **Rules**: System-generated, requires validation

### Fact
- **Purpose**: Verified claim or assertion
- **Attributes**: ID, workspace_id, statement, confidence, verified_at
- **Relationships**: Linked to KnowledgeNodes
- **Rules**: Version-tracked, requires sources

### Insight
- **Purpose**: AI-derived understanding or recommendation
- **Attributes**: ID, workspace_id, type, content, confidence, source
- **Relationships**: Linked to KnowledgeNodes, Decisions
- **Rules**: Generated by agents, audit trail maintained
