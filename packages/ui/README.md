# UI Component Library

Shared reusable UI component library built with React and Tailwind CSS.

## Purpose

Provides a consistent, production-grade design system across all Living Knowledge OS applications.

## Responsibilities

- Define reusable UI components (buttons, forms, layouts, etc.)
- Establish visual and interaction consistency
- Provide Storybook documentation
- Maintain component accessibility
- Export TypeScript types for all components

## Contents

- **Button**: Primary, secondary, and utility button variants
- **Card**: Container component with shadow and padding
- **Modal/Dialog**: Accessible modal dialogs
- **Sidebar**: Navigation sidebar component
- **Navbar**: Header and top navigation
- **Search Bar**: Input with search functionality
- **Avatar**: User avatar with fallback
- **Breadcrumb**: Navigation breadcrumb
- **Table**: Data table with sorting and pagination
- **Toast**: Toast notifications
- **Loading Spinner**: Loading indicator
- **Theme Toggle**: Dark/light mode switcher

## Dependencies

- React 19+
- Tailwind CSS 3+
- Radix UI (headless primitives)
- shadcn/ui (component pre-built on Radix)
